# GPO2025

Репозиторий проекта ГПО 2025 — Голосовой ассистент с эмоциями.

---

## Первоначальная настройка (один раз)

### 1. Установить Git
Скачать с https://git-scm.com/download/win и установить.

### 2. Настроить своё имя и email
```
git config --global user.name "Твоё Имя"
git config --global user.email "твой@email.com"
```

### 3. Клонировать репозиторий
```
git clone https://github.com/Sergey-zv/GPO2025.git
```
После этого появится папка `GPO2025` — работай в ней.

---

## Ежедневная работа

### Перед началом работы — получить последние изменения
```
git pull
```

### Добавить файлы и сохранить изменения
```
git add .
git commit -m "Что ты сделал"
git push
```

### Если хочешь добавить только один файл
```
git add имя_файла.ipynb
git commit -m "Описание"
git push
```

---

## Основные команды

| Команда | Что делает |
|---|---|
| `git pull` | Скачать последние изменения с GitHub |
| `git add .` | Подготовить все изменённые файлы к коммиту |
| `git status` | Показать какие файлы изменены |
| `git commit -m "текст"` | Сохранить снимок с описанием |
| `git push` | Отправить коммиты на GitHub |
| `git log --oneline` | История коммитов |

---

## Важно

- **Не добавляй большие файлы** (>100 MB) — GitHub не принимает. Храни датасеты на Kaggle или Google Drive.
- **Всегда делай `git pull` перед началом работы** — чтобы не было конфликтов.
- Файл `archive.zip` исключён из репозитория намеренно (слишком большой).
